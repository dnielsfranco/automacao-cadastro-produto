# Automação de Cadastro de Produtos

##  Descrição
Projeto de automação desenvolvido em Python para realizar cadastro automático de produtos em um sistema web.

A automação simula ações do usuário (mouse e teclado), realiza login e preenche formulários com base em uma planilha CSV.

##  Funcionalidades
- Abertura automática do navegador
- Login automático no sistema
- Leitura de dados via CSV
- Preenchimento automático de formulários
- Cadastro em massa de produtos

##  Tecnologias
- Python
- PyAutoGUI
- Pandas

##  Como executar

1. Instale as dependências:
pip install pyautogui pandas

2. Execute:
python main.py

## Observações
- O sistema depende da posição do mouse (coordenadas)
- Pode ser necessário ajustar conforme a tela
